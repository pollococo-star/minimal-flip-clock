# Minimal Flip Clock

Reloj flip online **minimalista** de alta calidad, inspirado en los clásicos relojes de estación de tren.

## Demo

**[Ver en vivo →](https://pollococo-star.github.io/minimal-flip-clock/)**

## Características

- Animación de flip realista (estilo estándar + sencillo)
- Diseño limpio y minimalista
- Modo oscuro / claro
- Formato 12h / 24h
- Mostrar u ocultar segundos
- Mostrar u ocultar fecha
- Pantalla completa (doble clic o botón)
- Persistencia de ajustes
- Completamente responsive
- Sin dependencias externas

## Controles

| Acción              | Cómo                          |
|---------------------|-------------------------------|
| Ajustes             | Icono de engranaje            |
| Cambiar tema        | Icono de sol                  |
| Pantalla completa   | Botón o doble clic            |
| Cerrar panel        | Clic fuera o tecla Escape     |
