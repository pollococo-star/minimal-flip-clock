# Minimal Flip Clock

Un reloj flip online **minimalista** inspirado en los clásicos relojes de estación de tren.

Diseño limpio, animación fluida de dígitos y sin distracciones.

## Demo

**[Ver en vivo →](https://pollococo-star.github.io/minimal-flip-clock/)**

## Características

- Animación de flip realista con CSS 3D
- Modo oscuro / claro
- Formato 12h / 24h
- Mostrar u ocultar segundos
- Mostrar u ocultar fecha
- Pantalla completa (doble clic o botón)
- Persistencia de ajustes (localStorage)
- 100% responsive
- Sin dependencias externas (solo Google Fonts)

## Uso

Simplemente abre `index.html` o súbelo a cualquier hosting estático (GitHub Pages, Netlify, Vercel, etc.).

## Controles

| Acción              | Cómo                          |
|---------------------|-------------------------------|
| Ajustes             | Icono de engranaje            |
| Cambiar tema        | Icono de sol/luna             |
| Pantalla completa   | Botón o doble clic            |
| Cerrar panel        | Clic fuera o tecla Escape     |
